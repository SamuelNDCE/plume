# Code of Conduct

We want Plume to be a welcoming project for everyone.

- Be respectful and assume good faith.
- Give and accept feedback on the work, not the person.
- No harassment, discrimination, personal attacks or unwelcome sexual attention.
- Do not publish other people's private information.

Maintainers may edit, hide or remove comments, issues and contributions that break these rules, and may block repeat offenders. To report a problem, use a private GitHub security advisory or contact the maintainer listed on the repository profile.

This is a short summary in the spirit of the Contributor Covenant 2.1.
